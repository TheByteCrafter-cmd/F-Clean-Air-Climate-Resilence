## 1. Executive Summary & UI Architecture

The Decision Intelligence Frontend Integration provides a clean, read-only civic dashboard interface for presenting multi-horizon environmental intelligence, risk scores, data quality statuses, and prioritized authority recommendations generated by the backend `DecisionIntelligenceEngine`.

## 2. Component Contract & Capabilities

The `DecisionIntelligenceView` component encapsulates all rendering and interaction logic for operational decision intelligence:

1. **Station Scope Header**: Explicitly bound to pilot station `Anand Vihar 8118` (`ANAND_VIHAR_8118`).
2. **Data Quality & Status Rendering**:
   - `READY`: Standard operation banner with green status indicator.
   - `PARTIAL`: Displays warning box listing missing telemetry evidence while showing available predictions.
   - `BLOCKED`: Displays prominent red execution block banner detailing reason code.
3. **Human Review Invariant**: Displays `Requires Human Review: YES` with no interactive controls or override toggles.
4. **Multi-Horizon Forecast Panel**: Displays predicted PM2.5 concentrations and 90% conformal uncertainty intervals for +1h, +3h, and +6h horizons.
5. **Operational Risk Assessment**: Highlights total composite risk score (0-100) and qualitative severity band (`LOW`, `MODERATE`, `HIGH`, `VERY_HIGH`).
6. **Prioritized Action Recommendations**: Ordered strictly by backend rule precedence, complete with trigger conditions, objectives, and audit reason codes.
7. **Audit Evidence References**: Renders exact backend tracking IDs for decision results, forecast inference, risk assessment, action recommendations, hotspot evidence, and fusion artifacts.
8. **Disclaimers**: Mandatory non-medical and non-causal attribution disclaimers rendered prominently at the base of the view.

The component communicates with the backend via `apiClient.evaluateDecision(payload)` in `frontend/src/api/client.ts`.
